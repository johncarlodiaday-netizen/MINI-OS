How to play

You are the lab technician. Each student print job is a process; the shared printer is the CPU. Keep the printer busy and the print queue short.

  1. Start runs the simulation. Pause stops it, Step advances one time unit, Reset reloads the workload.
  2. Pick an algorithm (FCFS, SJF, Round Robin, Priority) and a quantum, then compare results.
  3. Click a row in the roster to select a job, then use system calls to add a job, cancel it, add or remove a document (thread), send a job to the scanner (I/O), let other jobs print first (yield), or start the print-jam (deadlock) demo and then break it.
  4. Click any chart block for a plain-language Why? explanation.
  5. Drag the time machine slider to rewind; press Start to replay from that point.
  6. Story view / OS view switches the whole dashboard using the same simulation.
  7. Benchmark runs all 4 algorithms on all 3 workloads.
  8. Dark / Light switches the colour theme (your choice is remembered).

While it runs you will see: the printer glowing and sliding out pages with a progress bar, new jobs sliding into the queue, new Gantt blocks growing in, rows flashing when their state changes, a red flash on every context switch, and confetti when every job is collected. These effects are turned off if your device is set to reduce motion.
